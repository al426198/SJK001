# SJK001: Cyber-physical and Robotic Intelligent Systems

This repository stores the code developed during the practical sessions of this subject. 
All sessions are based on Unibotics tutorials and have been developed using their JDE:
- [Line Following Exercise](https://jderobot.github.io/RoboticsAcademy/exercises/AutonomousCars/follow_line/): a PID reactive control capable of following a line painted on a racing circuit.
- [Drone Rescue People](https://jderobot.github.io/RoboticsAcademy/exercises/Drones/rescue_people): a quadrotor that recognizes the faces of lost people and saves their locations in order to perform a subsequent rescue maneuver.
